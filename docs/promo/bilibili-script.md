# B 站抽象视频脚本（30 秒内，对标大肥鱼风格）

> 基调：不解释、不铺垫、纯行为艺术 + 屏幕上的动作堆叠。全片无解说，BGM 用整活音效流。
> 素材：官方 DSH Desktop 录屏（OBS 只录窗口区域，1080p/60fps），鲸鱼娘挂件为主角。
> 节奏：8 个镜头，平均 3~4 秒。结尾 5 秒留安装命令压屏。

## 分镜

| # | 时长 | 画面 | 音效 | 字幕（大字，可选） |
|---|---|---|---|---|
| 1 | 3s | 黑屏 → 鲸鱼娘突然从屏幕右下角"坠入"画面（甩抛落地），静止卖萌 1 秒 | 重物落地"咚" + 一声 eng↑ | 无 |
| 2 | 3s | 鼠标疯狂摸头 → 摸头手速极快，角色被压扁弹起（squash）| 雷霆笑声（招牌）| 「我 摸」 |
| 3 | 4s | 中键弹弓：拉长蓝色水滴线 → 松手 → 角色带着**拖尾**横穿屏幕 → 撞墙"啪"回弹 | 弹弓皮筋"嗖" + 钢管落地 | 「weeeeee」 |

| 5 | 5s | **哄睡长镜头**：角色 1.1 秒缓慢瘫倒 → Zzz 冒出来 → 画面静止 2 秒（留白）| 打呼噜 + 音乐骤停 | 「她 睡 了」 |

## 制作注

- 全片无 BGM 或只用一段 8-bit loop，靠音效扛节奏（大肥鱼流派的精髓：音效密度 > 旋律）
- 镜头 3 的拖尾是 0.4.3 新特性，**必须拍到**（这是和旧版桌宠视频的差异点）
- 镜头 5 的"静止 2 秒"是灵魂——抽象视频的高潮是突然安静
- 标题党但诚实：「这只鲸鱼娘会自己睡觉」/「我给 DSH 养了只会要饭的鲸鱼」二选一
- 简介区放：一行安装命令 + GitHub 链接 + 「官方端也能用」一句
- ⚠️ 素材录好后先发给 ZCode 过一遍剪辑点，字幕别写错命令
