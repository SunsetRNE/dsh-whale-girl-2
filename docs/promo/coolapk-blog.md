## 酷安版

**标题：给 DSH 养了只会记账还会躺平睡觉的鲸鱼娘🐳**

DSH 右下角挂了一只鲸鱼娘，能干这些事：

- 💰 盯余额/今日用量/上下文占用，余额低了会喊你充值
- 🪢 能拖能甩能弹，中键弹弓能把她射出去，高速移动带蓝色拖尾
- 😴 没任务又没人理她，5~10 分钟后原地瘫倒睡觉，头顶冒 Zzz，戳一下秒醒
- 💬 会说话（"让我走~我在打电话~"这种），点她就开口

安装一条命令（官方端/第三方端都行）：

```
dsh plugin --profile desktop add dsh-whale-girl
```

不占额外进程，空闲几乎不吃 CPU，立绘音效全内嵌不怕断网。开源 MIT。
